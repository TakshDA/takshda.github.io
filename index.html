Premier League Predictor

May 2026 — Jul 2026
↗ View on GitHub

An end-to-end machine learning project that predicts Premier League match outcomes and individual player performance, built from raw historical data all the way through to an interactive Power BI dashboard. It runs the complete analyst workflow start to finish: sourcing and cleaning the data, engineering features, training and validating models, storing results in a SQL database, and visualizing everything for a non-technical audience.

3,398
Matches across 11 seasons
  • Collected and cleaned 3,398 matches spanning 11 Premier League seasons, standardizing messy raw data into a single, consistent, model-ready dataset.
  • Engineered team-strength features using an ELO rating system that updates after every match, capturing form and relative strength as it changes over time.
  • Trained a scikit-learn match-outcome model that reached 49.5% accuracy, beating the naive home-win baseline of 42.6%.
  • Built a separate player-level model with Ridge regression (predict_players.py) to project individual performance, outperforming a persistence baseline by 17.9%.
  • Created a SQL layer with a SQLite database (build_database.py) and a set of analysis queries (run_queries.py) to store predictions and run structured analysis on the results.
  • Surfaced an analytical finding during exploration: home advantage declined from 48.4% to 42.6% across the seasons studied.
  • Delivered the results in an interactive Power BI dashboard featuring an accuracy callout, ELO team rankings, player projections, and a full match-prediction table.
  • Published the complete project with a documented README on GitHub and wrote it up on LinkedIn for a technical audience.
